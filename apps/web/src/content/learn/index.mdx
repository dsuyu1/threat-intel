# Learn

Threat Intel Platform helps security teams turn raw intel (feeds, CVEs, IOCs) into:

- A prioritized queue of **findings** to triage
- A traceable **knowledge graph** (entities + relationships + evidence)
- (Pro) a **Navigator** workflow that turns techniques into **detections** and risk entries
